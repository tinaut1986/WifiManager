# WifiManager

A 3DS homebrew for managing your console's Wi-Fi configuration slots.

It lets you **back up**, **restore** and **swap** the three system Wi-Fi slots,
and now also **import a network from a QR code** — handy when you travel a lot,
share a connection from a phone, or simply want more than three saved networks.

## Features

- Modern citro2d interface (dual-screen, touch + D-pad).
- Back up any console slot to a `.bin` file on the SD card.
- Restore / copy a backup into any of the three console slots.
- **Scan a Wi-Fi QR code with the outer camera** and:
  - save it as a backup, or
  - write it straight into a console slot.
- Supports the standardised `WIFI:S:<ssid>;T:<WPA|WEP|nopass>;P:<pass>;H:<true|false>;;`
  payload (as generated by Android/iOS and most routers) **and** a plain-text
  fallback (`SSID` on its own, or `SSID` + newline + `password`).
- Show / hide passwords, delete backups.

## Controls

| Input | Action |
|-------|--------|
| D-pad Left/Right | Select console slot |
| D-pad Up/Down | Move through the list |
| A | Apply selection (scan QR / back up slot / write backup to slot) |
| X | Delete the selected backup |
| Y | Toggle password visibility |
| L | Open the QR scanner |
| SELECT | Help |
| START | Quit |

Backups are stored in `sdmc:/3ds/WifiManager/`.

## Building

Requires [devkitPro](https://devkitpro.org/) with `devkitARM`, `libctru` and
`citro2d`/`citro3d` (`pacman -S 3ds-dev`).

```
make
```

Produces `out/WifiManager.3dsx` (and `out/WifiManager.cia` when `makerom` and
`bannertool` are on `PATH`).

## Third-party code

- `source/checksum.h` and `source/crc16.c` come from
  [libcrc 2.0](https://github.com/lammertb/libcrc/tree/v2.0) by lammertb (MIT),
  trimmed to just the CRC-16 routine used to re-checksum a Wi-Fi slot.
- `source/quirc/` is [quirc](https://github.com/dlbeer/quirc) by Daniel Beer
  (ISC), used to decode QR codes from camera frames.
